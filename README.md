# 千葉県 災害ボランティアセンター一覧

令和8年8月千葉豪雨（8月13日）と令和8年台風25号による、千葉県内の災害ボランティアセンター（災害VC）の開設状況と募集情報をまとめたWebページです。

- **公開URL**：<https://chiba-saigai-volunteer-navi.vercel.app/>
- **ソース（GitHub）**：<https://github.com/Sumitarou/chiba-saigai-volunteer-navi>
- **情報の基準日**：2026年10月4日

> ⚠ 掲載内容は参考情報です。募集状況は日々変わります。参加する前に、必ず各市町村の社会福祉協議会（社協）の公式発表を確認してください。

---

## 機能

- **募集範囲による区分**：全国から／千葉県内から／市町内・近隣のみ／調整中・準備中／通常VCで対応、の5区分に分けて、色分けして表示します。
- **絞り込みと検索**：区分ボタンでの絞り込みと、市町村名や作業内容（例：「畳」「土砂」）でのキーワード検索ができます。
- **市町村ごとのカード**：開設状況、活動期間、募集範囲、募集人数、条件、持ち物、注意点（休みの日、重労働、断水など）を表示します。
- **公式リンク**：各市町村の詳細ページ、社協HP、Facebook、行政HPへのリンクがあります。
- **参加前の案内**：千葉県災害ボランティアセンターの問い合わせ先、ボランティアバスでの支援方法、ボランティア活動保険、高速道路の無料措置を案内します。
- **情報源の区別**：表示の見た目で、どこから来た情報かが分かるようにしています。

  | 表示 | 情報源 |
  |---|---|
  | カード本文（活動期間・募集範囲） | [千葉災害ボランティア情報](https://www.saigai-chiba.com/)（千葉県社会福祉協議会の公式まとめサイト） |
  | 青枠「募集サイト掲載（○/○更新）」 | 各社協がボランティア募集サイトに掲載した募集情報 |
  | 灰色「補足（独自集計）」 | 各社協の発信をもとにした独自の集計 |
  | 黄色「補足（参加者情報 10/5）」・赤い「10/5更新」の印 | ボランティア参加者から寄せられた情報 |
  | 橙タグ「情報差異あり」 | 情報源によって内容が食い違っている項目 |

- **さまざまな環境への対応**：スマホでも見やすいレイアウトです。印刷すると絞り込みボタンは表示されません。外部のファイルを読み込まないので、ファイルを直接開いてもオフラインで表示できます。JavaScript が動かない環境でも、全件を読めます。

## 更新手順

1. `index.html` の該当する市町村のカード（`<article class="card item">`）や表の行を書き換えます。
2. ヘッダーの「**2026年○月○日時点**」と、フッターの「**最終更新**」の日付を必ず書き換えます。
3. ブラウザで `index.html` を開き、表示・絞り込み・リンクを確認します。
4. コミットして push します。
   ```bash
   git add index.html
   git commit -m "募集情報を更新（10/5時点）"
   git push
   ```
5. 1分ほど待ってから本番URLを開き、反映されていることを確認します。うまくいかない場合は、Vercel のダッシュボードの **Deployments** を確認してください。

### 区分を移すときの目安

| 区分 | `section` の `data-cat` | 判断基準（公式の「募集範囲」の記載） |
|---|---|---|
| 全国から | `all` | 「全国」 |
| 千葉県内から | `pref` | 「千葉県内」「県内」 |
| 市町内・近隣 | `local` | 「市内」「近隣市町」「在住在勤」など |
| 調整中・準備中 | `pending` | 活動期間か募集範囲が「調整中」、または開設準備中 |
| 通常VCで対応 | `normal` | 災害VCを置かず、通常のVCで対応 |

ボランティアセンターが終了した市町村は、カードを削除するか、「調整中・準備中」の区分に「終了」と表示して残してください（終了の告知として役立ちます）。

## 運用・保守の留意点

### 情報の正確さ（最優先）
- **基準日を必ず更新してください。** 古い情報が新しく見えることが、最も危険です。更新しなかった日も、「○日時点」の表示で情報の古さが分かるようにしておきます。
- **一つの情報源だけで判断しないでください。** 区分や開設状況は、公式まとめサイトと各社協の発表を突き合わせて確認します。食い違いがある場合は、片方を黙って採用せず、「情報差異あり」と表示します。
- **電話番号・日付・人数は、必ず元の情報で確認してください。** AI による要約や転記には、読み違いが起こり得ます。
- **災害が落ち着いたら**：すべてのボランティアセンターが終了した時点で、ページの先頭に「受付は終了しました」と表示します。その後、ページを残すか、Vercel のプロジェクトを削除するかを判断してください。古いページが検索結果に残り続けないよう注意が必要です。

### GitHub
- **このリポジトリは公開（public）設定です。** 置いたファイルは誰でも見られます。
  - スクリーンショット、個人の連絡先、被災者の情報、作業メモは入れないでください。
  - `.gitignore` で、`sample.txt`、`*.zip`、`index_backup_*.html` を対象外にしています。
- **バックアップは git の履歴で行ってください。** `index_backup_*.html` のようなコピーは不要です。過去の版は `git log` で確認でき、`git checkout <コミット> -- index.html` で戻せます。
- **コミットメッセージに基準日を入れてください。** 例：「募集情報を更新（10/5 15時時点）」。どの時点の情報かを後から追えるようにするためです。
- 複数人で更新する場合は、ブランチを分けて Pull Request で互いに確認すると、誤った情報の公開を防げます。

### Vercel
- **共有するのは本番用のURLだけにしてください。** push ごとに作られる長いURL（プレビュー用）は、初期設定ではログインしないと見られません。
- **ブランチを分けると、本番の前に確認できます。** main 以外のブランチに push すると、プレビュー用URLで表示を確かめてから main にマージできます。
- **Hobby プランは、個人の非商用利用が前提です。** 団体の正式なサイトとして運用する場合や、広告を載せる場合は、プランを見直してください。
- **GitHub との連携が切れると、自動公開が止まります。** GitHub 側で Vercel のアクセス権を外さないでください。
- **Web Analytics**：Project → **Analytics** → **Enable** で有効にし、その後のデプロイから計測が始まります。`index.html` の `<head>` にある `/_vercel/insights/script.js` の読み込みを削除しないでください。Hobby プランでは、月あたりの計測数に上限があります（詳しくは Vercel の料金ページを参照）。
- **独自ドメインを使う場合**：Project → Settings → Domains で追加できます。その場合も、案内するURLは一つに統一してください。

### 公開範囲と検索エンジン
- 試験公開中は、`<head>` 内に `<meta name="robots" content="noindex">` を入れると、検索結果に出にくくなります（現在は入っていません）。
- 本公開の前に、「残課題」の中の優先度が高い項目を解決してください。

### LINE などでの共有
- HTMLファイルを直接送らず、**URLを共有してください**（スマホで開けない人が多く、古い版がトーク履歴に残るため）。
- 投稿文には、「○月○日○時時点」と「最新情報は各社協で確認してください」を添えてください。

### 表示の確認
- 更新した後は、iOS の Safari、Android の Chrome、LINE 内のブラウザで表示を確認するのが理想です。
- Vercel の公開完了画面の縮小画像では、日本語が表示されないことがあります。これは画像を作るサーバー側の事情で、本ページの不具合ではありません。
